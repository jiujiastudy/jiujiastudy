# Tests

Offline, standard library only:

    python -B -m unittest discover -s tests -v

About half a minute. Nothing talks to the internet: `mockcanvas.py` serves synthetic
Canvas data on 127.0.0.1, and `_coach_runner.py` refuses every other connection,
DNS lookup and child process. When a test unsets `CANVAS_TOKEN`, the runner also
hides the Windows registry, so a token saved on the computer is never read.

The real-browser login test in `test_login_mode.py` is skipped unless Playwright is
installed and `JIUJIASTUDY_BROWSER_TESTS=1` is set. It opens a browser window for a few
seconds against a local mock Canvas that hands out a session cookie.

## What runs

`test_golden.py` runs `tools/coach.py` for four synthetic schools and compares the
output with `golden/`. Each run gets a fresh fake home: USERPROFILE, HOME, APPDATA,
TEMP and the archive are all inside a temp folder, with `CANVAS_TOKEN=dummy` and
`COURSECOACH_NO_DIALOG=1`. The clock is pinned to the scenario's `now`, and every
command gets `--date`.

| scenario | shape |
|---|---|
| `au_semester` | ABCD1234 codes, 13 weeks plus a break, weekly modules, Sydney course with the student's clock in Shanghai |
| `us_quarter` | "MATH 3B: Calculus" names, topic and "Unit N" modules, Los Angeles, items_url-only modules, paging |
| `uk_term` | reading week, "Lecture N" and "Seminar N" modules, London near the clock change |
| `cn_names` | Chinese names and codes, 第N周 / 第N讲 modules, full-width punctuation, Shanghai |

Steps per scenario: status before collect, `collect --touch`, status, radar and study
(text and `--json`), `radar --write`, `study --write`, status again, a cached collect,
and `collect --touch --json` in a second fresh archive. It also checks the files
written (plan JSON, DDL雷达.md, visible text of both HTML pages, config, state,
snapshot, digest, file tree) and the exact Canvas requests.

Paths are masked (`<ARCHIVE>`, `<ROOT>`, `<CODE>`), the mock URL becomes `<CANVAS>`,
and the pinned time becomes `<NOW>`. A time within 3 days of the real clock becomes
`<WALLCLOCK>`: the tool read the real clock (today only `state.last_seen` does).

`test_harness.py` checks the mock, the fixtures and the isolation. Its probe only
ever aims at this computer (two local ports, a numeric address resolved with
`AI_NUMERICHOST`), so a broken guard fails the test without reaching the network.

`test_cli.py` checks the command-line contract and the module layout:

- `--version` prints the name and version from `tools/brand.py`;
- `status` before setup exits 0, and its `--json` has `needs_setup: true`;
- any unexpected error prints one Chinese line and exits 2 (`--json`: `{"error", "exit": 2}`),
  and so does a mistyped command (unknown flag, bad value, missing argument);
- `tools/canvas_api.py` run on its own with no token prints one JSON error line and exits 2;
- with no time zone data at all (`STC_NO_TZDATA=1`: empty zone path, `tzdata` hidden)
  commands still work and print one note;
- Canvas text in the collect digest and in study notes is fenced, and the HTML pages are not;
- the page footer takes plain text only;
- the product name appears in `tools/` only in `brand.py`, every module imports on its own,
  and no function body is copied into two modules.

`test_doctor.py` checks doctor against the mock: exit 0 after a successful first
setup and on the next run, 1 once set up but not connected, 2 when nothing can be
set up; and the skill-location check (SKILL.md directly under a skills folder a
host reads: `.claude/skills`, `.codex/skills`, `.agents/skills`, `$CODEX_HOME/skills`
or a plugin's `skills/`).

`test_moodle.py` runs the Moodle side against `mockmoodle.py` (scenario
`fixtures/moodle_term`, see its README) with the urllib transport
(`JIUJIASTUDY_MOODLE_TRANSPORT=urllib`); "logged in" is a `login.json` with
`lms: moodle` plus the mock's session cookie. It walks doctor → collect → radar →
study → downloads in one archive, checks every coverage point of the scenario
README, that times stay ISO strings, that an expired login stops collect with
"log in again", and that nothing writes: non-whitelisted ajax, `api post` /
`api upload` are refused and the mock sees no write request. Its real-browser test
is gated like the Canvas one. `test_mdl_pages.py` unit-tests the page parsers.

## Changing behaviour on purpose

The goldens were captured from the untouched package, then re-captured only where a
fix changes output on purpose (B0: the Canvas text fence changed `01_collect_touch.txt`,
`07_study_json.json`, `09_study_write_json.json` and `artifacts/plan.json` in each
scenario). A refactor must leave them unchanged. If a change is meant to alter
output, re-capture and review the diff:

    python tests/harness.py capture                # from this checkout
    python tests/harness.py capture --code DIR     # from another checkout
    python tests/harness.py run us_quarter -- study --json   # one command, isolated

Fixtures are generated by `fixtures/make_fixtures.py` (needs time zone data);
rebuilding them changes the goldens. `tzdata/` holds the five zone files the
scenarios use, so every platform reads the same rules without the `tzdata` package.

Environment: `STC_TEST_TMP` sets where fake homes go, `STC_KEEP_HOMES=1` keeps them,
and `STC_CODE_DIR` tests another checkout.
